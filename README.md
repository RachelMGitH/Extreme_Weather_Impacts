# EDS 223 Homework Assignment 4: Identifying The Impacts of Extreme Weather

This repository houses the work completed by Rachel Miller for the EDS 223 homework assignment 4. The aim is to visualize the impacts of the February 2021 winter storms on power outages in Texas using remotely-sensed data on nighttime light intensity and OpenStreetMap data on buildings and roads.

## Data Access
Some data wrangling was performed on the data before this project. The prepared data was sourced from a Google Drive [link](https://drive.google.com/file/d/1bTk62xwOzBqWmmT791SbYbHxnCdjmBtw/view), but originates from:

1. NASA’s Level-1 and Atmospheric Archive & Distribution System Distributed Active Archive Center (LAADS DAAC) [link](https://ladsweb.modaps.eosdis.nasa.gov/)
2. OpenStreetMap data on buildings and roads distributed through Geofabrik [link](https://download.geofabrik.de/)
